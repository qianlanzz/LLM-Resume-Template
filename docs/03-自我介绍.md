## 版本一：通用版（约 2 分钟）

面试官好，我叫张哲，目前是南京理工大学软件工程专业的硕士研究生，研究方向是 LLM Agent 开发与应用。

在实习方面，我目前在中国电子科技集团第二十八研究所实习，参与航天领域 AI 模型全生命周期管理平台的开发。我主要负责三个模块：一是基于 Qwen3-Embedding 和 FAISS 构建的语义检索服务，解决了关键词检索召回率不足的问题；二是三路混合推荐引擎，结合 Redis 缓存和 Celery 异步回填；三是基于 DBSCAN 的多维异常检测和容量预警系统。

在个人项目方面，我独立开发了开源 Agent 框架 AgentBot，基于 LangGraph 实现了带工具调用的 CLI Agent，支持多模型提供商热切换、长对话自动压缩（Token 用量降低约 60%）、沙盒安全执行，以及内置 WikiAgent 知识库子智能体。

另外我还主导开发了一套教辅录题审核一体化系统，技术栈是 Fastify + Prisma + PostgreSQL + BullMQ，核心是基于 MinerU 的自动切题模块和 Prometheus + Grafana 监控链路。

在竞赛方面，我在 ICCV 2025 多项选择题视频问答赛道和 WACV 2025 目标距离估计赛道都拿到了冠军，有多模态模型微调和推理增强的实战经验。

我的技术栈覆盖 Python 后端（Django/FastAPI）、Node.js（Fastify）、Vue 3 前端，以及 Docker 容器化部署。我对 Agent 框架设计和 LLM 工程化落地比较感兴趣，希望能在贵公司继续深耕这个方向。

## 版本二：Agent/LLM 方向岗位（约 2 分钟）

面试官好，我叫张哲，南京理工大学软件工程硕士在读，方向是 LLM Agent 开发。

我在 Agent 方向有比较系统的工程实践。我独立开发了 AgentBot，这是一个基于 LangGraph StateGraph 的 CLI Agent 框架。核心是 agent-tools 循环工作流，支持条件路由和多轮工具调用。我在这个项目里解决了几个工程化问题：长对话 Token 膨胀问题（按回合压缩，Token 降低 60%）、工具安全执行（路径前缀校验 + 危险命令拦截）、多模型提供商统一适配（OpenAI/Anthropic/阿里云等 6 家）。

WikiAgent 是 AgentBot 的子系统，我用自研的轻量 ReAct 循环实现了知识库的摄入、查询、健康检查三个专用子智能体，知识库以标准 Markdown 存储，兼容 Obsidian 图谱可视化。

在实习项目里，我也把 LLM 用在了实际业务场景：录题审核系统里用大模型做 PDF 题目的结构化抽取（题干、选项、答案、解析），结合 MinerU 的块级坐标解析，实现了自动切题流程。

技术栈上，我熟悉 LangGraph、LangChain、MCP 协议，有 RAG、LoRA 微调、GRPO 强化学习的实践经验，了解 vLLM 推理部署。

## 版本三：后端/全栈岗位（约 2 分钟）

面试官好，我叫张哲，南京理工大学软件工程硕士在读。

我有比较完整的全栈开发经验。在中电科 28 所实习期间，我用 Django 开发了语义检索服务（FAISS 向量索引 + Django Signal 增量更新）、混合推荐引擎（Redis 缓存 + Celery 异步回填 + 分布式锁防穿透）和基于 DBSCAN 的异常检测模块。

在录题审核系统项目里，我主导了后端架构设计，技术栈是 Fastify v5 + Prisma + PostgreSQL + Redis + BullMQ。核心挑战是处理 PDF 解析这类长任务：用 BullMQ 把耗时任务异步化，前端通过 SSE 实时获取进度；同时搭建了 Prometheus + Grafana 监控链路，自定义了队列积压、任务 P95 延迟、Worker 心跳等指标，配置了告警规则。

前端方面，我用 Vue 3 + TypeScript 开发了录题工作台，支持 PDF 双栏浏览、框选 OCR、公式渲染、草稿自动保存。

DevOps 方面，项目用 Turborepo 管理 monorepo，Docker Compose 多环境部署，Caddy 做反向代理。

## 常见追问准备

**Q：你的研究方向是什么？**
> LLM Agent 的工程化落地，具体是工具调用可靠性、长对话上下文管理、Agent 安全执行和审计。

**Q：你最有挑战性的项目是哪个？**
> AgentBot 的长对话压缩设计。核心难点是如何在不丢失关键上下文的前提下压缩 Token。我的方案是按完整回合分组，保留最近 N 轮，丢弃部分用 LLM 生成摘要注入 System Message。难点在于摘要质量直接影响后续对话效果，需要精心设计摘要 Prompt。
