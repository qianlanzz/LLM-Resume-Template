项目内容（概述）：

面向教辅录题场景独立设计并实现 Agent 工作流，将教材 PDF 解析、结构化切题、AI 质检、人工裁决、安全落库串成完整生产链路，把传统人工录题升级为“Agent 生成 + AI 复核 + 人工兜底”；平台累计承载 6,862 本教材、72.9 万页 PDF、125.2 万道题目，其中 6,219 本完成抽检、3,081 本完成正式入库。技术栈：Vue 3 / Fastify / PostgreSQL / Redis / BullMQ / MinerU / 火山方舟。

本人职责：

1. Detector → Verifier → Executor 多阶段质检 Agent：Detector 使用文本模型批量扫描 OCR 与题目内容，输出包含问题位置、原文、修改建议及可修复性的结构化问题单；Verifier 调用多模态视觉模型，对照 MinerU 坐标实时裁剪的 PDF 原图逐条复核，过滤缺乏原图依据的文本幻觉；Executor 在写回前执行原文唯一定位、内容哈希及稿件版本校验，仅允许通过校验的问题自动修复，其余降级人工处理，并与 revision / 编辑锁联动形成 Human-in-the-loop 闭环。AI 质检上线后已覆盖 80 本教材、14.4 万道题，发现约 1.5 万条问题；质检后内容准确率由约 95% 提升至 98%，单本教材平均抽检耗时由 40 min 降至 18 min，降低约 55%。
2. Grounding 驱动的文档结构化抽取：切题 Agent 不直接生成或改写题目正文，而是消费 MinerU 带 ID 的版面块，通过自定义结构化协议输出题号、题干、选项、答案、解析对源块 ID 的引用，再由服务端回填原始文本与坐标，使每个字段均可追溯至 PDF 原始区域；结合目录路径、邻近章节与页面归属约束处理跨页、双栏及章节边界场景，题目页与答案页分离时通过“目录范围 + 题号”完成跨页题答配对，并采用“归属不确定则宁可漏提”的策略降低跨目录误切与重复切题。目前 MinerU 版面解析已稳定处理 2,225 本教材、29.7 万页 PDF。
3. 可恢复、可审计的 LLM Workflow Runtime：基于 BullMQ 统一编排 PDF 拆页、MinerU 解析、自动切题、OCR 与 AI 质检等分钟级任务，接口即时返回 jobId，由 Worker 异步消费，并以批次 checkpoint 实现失败断点续跑，已成功批次自动跳过，避免重复执行和重复计费；通过输入内容哈希 + Prompt 版本进行幂等去重，结合 Redis 锁防止并发重复发起。累计支撑 464 万次 OCR 调用、126 亿 Tokens；记录每次调用的模型、Token、费用及 rawResponse，并通过 Prometheus + Grafana 监控任务 P95、队列积压与 Worker 心跳，实现模型调用成本、任务执行链路及运行状态可观测。
