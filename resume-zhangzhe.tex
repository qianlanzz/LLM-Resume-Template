\sectionTitle{项目经历}{\faCode}
\begin{itemize}
  \item \textbf{教辅教材智能解析与 AI 质检平台} \hfill 2026.02 -- 至今
  \begin{itemize}
    \item \textbf{项目概述}: 面向教辅数字化录题场景，独立设计并实现集教材 PDF 解析、智能切题、AI 质检、人工校对与题目入库于一体的业务平台，形成从非结构化教材到结构化题库的完整处理流程。平台累计承载 6,862 本教材、72.9 万页 PDF、125.2 万道题目。技术栈：Vue 3 / Fastify / PostgreSQL / Redis / BullMQ / MinerU / 火山方舟。
    \item \textbf{智能切题}: 针对 LLM 难以精确定位 PDF 内容区域的问题，设计 MinerU 版面解析与 LLM 语义关联相结合的切题方案：将 PDF 解析为带原文及坐标的细粒度文本块并编号，由 LLM 识别题干、选项、答案和解析对应的块 ID，服务端再映射还原原文与坐标，实现题目字段的精确定位与结构化抽取；结合章节及题号信息，完成跨页题目识别与题答配对。
    \item \textbf{AI质检与人机协同审核}: 针对人工逐题审核效率低、视觉模型调用成本高的问题，设计``文本初筛 $\rightarrow$ 视觉复核 $\rightarrow$ 人工审核''的分级质检流程；利用文本模型批量识别疑似错误，再基于原图进行视觉核验，生成结构化问题清单辅助人工定向审核。累计覆盖 80 本教材、14.4 万道题，单本教材平均抽检耗时由 40 min 降至 18 min。
    \item \textbf{异步任务编排与断点恢复}: 针对教材解析与大模型调用耗时长、任务易中断的问题，基于 BullMQ + Redis 构建异步处理流水线，实现 PDF 拆页、文档解析及智能切题的任务调度与 Worker 消费；通过批次级 Checkpoint 记录处理进度，支持失败重试、断点续跑及已完成结果复用，结合 SSE 实现实时进度推送，并接入 Prometheus + Grafana 监控任务延迟与队列状态。
  \end{itemize}
\end{itemize}
