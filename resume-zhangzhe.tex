\sectionTitle{项目经历}{\faCode}
\begin{itemize}
  \item \textbf{AgentBot · 大模型智能体工具} \hfill 2025.10 -- 至今
  \begin{itemize}
    \item 用 LangGraph StateGraph 实现 CLI Agent 主循环，将 LLM 决策节点和 ToolNode 显式拆开，通过条件边判断是否继续调用工具；Provider 层统一适配 OpenAI、Anthropic、阿里云及 OpenAI 兼容接口，运行时可切换模型。
    \item 设计两层记忆：长期记忆用 Markdown 保存用户偏好，由 LLM 通过工具调用主动更新；短期对话通过 SQLite Checkpointer 按 thread 保存，超过 40 轮后压缩旧上下文并保留最近 10 轮，长对话 Token 用量降低约 60\%。
    \item 内置时间、计算器、任务调度、文件读写、Shell 等 12 个工具，统一走 LangChain @tool 接口；文件和 Shell 操作限定在沙盒目录内，路径解析后做前缀校验，并拦截高风险命令和超时进程，减少 LLM 误操作。
    \item 开发 WikiAgent 子智能体，支持摄入 PDF、URL 和文章，抽取实体、交叉引用并写入 Markdown 知识库；按摄入、查询、健康检查拆分职责，可扫描死链、孤立页面和矛盾内容，知识库可直接用 Obsidian 查看关系图。
    \item 为 Agent 执行过程增加 JSONL 审计日志，记录模型输入、工具调用、工具返回、最终回复和系统动作；配合 Rich 终端输出，可回放一次任务的完整决策链，定位工具参数错误和上下文污染问题。
  \end{itemize}

  \item \textbf{教辅录题审核一体化系统} \hfill 2025.06 -- 至今
  \begin{itemize}
    \item 面向教辅录题从 Excel、多工具协作迁移到统一平台的需求，基于 Vue 3 + TypeScript、Fastify + Prisma + PostgreSQL + Redis 开发录题工作台和后端服务，覆盖教材上传、PDF 浏览、框选 OCR、人工校对、质检和入库。
    \item 开发自动切题工作流模块，利用 MinerU 输出的块级坐标和目录结构解析教材 PDF，再用大模型抽取题号、题干、选项、答案和解析；通过``章节标题 + 题号''做题答配对，解决题目页和答案页分离的问题。
    \item 基于 BullMQ 承接 PDF 拆页、MinerU 解析、OCR 调用和自动切题等长任务，接口只返回 jobId，Worker 异步消费；前端通过 SSE 获取处理进度，避免几分钟级任务阻塞 HTTP 请求。
    \item 开发 ops-monitor 服务接入 Prometheus + Grafana，补充 API 延迟、队列积压、任务等待/执行时长 P95、Worker 心跳等指标，并配置 Worker 离线、API P95 超阈值和机器高 CPU 告警。
  \end{itemize}
\end{itemize}
