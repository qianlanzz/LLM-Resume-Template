\sectionTitle{项目经历}{\faCode}
\begin{itemize}
  \item \textbf{AgentBot · 大模型智能体工具} \hfill 2025.10 -- 至今
  \begin{itemize}
    \item 基于 LangGraph StateGraph 搭建的 CLI Agent，核心是 agent $\leftrightarrow$ tools 循环工作流，支持多轮工具调用与条件路由；通过统一的 Provider 工厂适配 OpenAI / Anthropic / 阿里云等 6 家模型 API，运行时可热切换。
    \item 记忆分两层：长期记忆用 Markdown 文件存用户偏好，LLM 通过 Tool Call 自己决定什么时候更新，跨会话保留；短期记忆基于 SQLite Checkpointer 存完整对话，按回合切分，超 40 轮后自动让 LLM 把旧对话压缩成摘要再裁掉原文，长对话 Token 用量降低约 60\%。
    \item 内置 12 个工具（时间、计算器、任务调度、文件读写、Shell 执行等），工具调用走 LangChain @tool 标准接口；文件和 Shell 操作限制在沙盒目录内，通过路径前缀校验拦截穿越，正则匹配拦截 rm -rf 等危险命令，Shell 执行设 60s 超时。
    \item 内置知识库子智能体（WikiAgent），支持自动摄入 PDF / URL / 文章并提取实体与交叉引用，写入结构化 Markdown Wiki；设计摄入、查询、健康检查三个专用子智能体分工协作，健康检查可扫描死链、孤立页面与矛盾内容并自动修复；知识库以标准 Markdown 存储，兼容 Obsidian 图谱可视化，支持 OpenAI 兼容的多种 LLM 后端。
    \item 所有 LLM 输入、工具调用、工具返回、AI 回复、系统动作共 5 类事件写入 JSONL 审计日志（单例 + 内存队列 + 守护线程异步落盘），配套 Rich 终端可实时查看 Agent 每一步的决策过程。
  \end{itemize}

  \item \textbf{教辅录题审核一体化系统} \hfill 2025.06 -- 至今
  \begin{itemize}
    \item 原有教辅录题依赖 Excel + 多工具协作，流程碎片化、效率低，需要一套打通上传、录题、质检、入库全链路的一体化系统。
    \item 基于 Vue 3 + TypeScript、Fastify + Prisma + PostgreSQL + Redis 开发录题工作台及后端服务，支持 PDF 双栏浏览、框选 OCR、公式渲染、草稿自动保存，打通教材上传到结果入库的完整链路。
    \item 主导自动切题模块，基于 MinerU 的块级坐标解析与目录分段能力将教材 PDF 转换为结构化内容，结合大模型完成题号、题干、选项、答案、解析抽取，基于``章节标题 + 题号''实现题答配对，生成标注结果回写工作台。
    \item 基于 BullMQ 承接 PDF 拆页、MinerU 解析与自动切题等长任务，避免重任务阻塞工作台；补充队列监控告警、草稿缓存与历史恢复、提交前校验等机制。
    \item 设计并落地 Prometheus + Grafana 监控链路，开发 ops-monitor 服务补充 HTTP 请求耗时、队列积压、任务等待/执行时长 P95、Worker 心跳与离线状态等自定义指标；配置 API P95、Worker 离线、机器高 CPU 等告警规则，提升长任务链路的可观测性与异常发现效率。
  \end{itemize}
\end{itemize}
